# WORK APPLY BOT

Personal job application tracking and automation system.

## Goal

Automatically track job applications from various sources such as:

- Job portals
- Email
- Browser extension

## Roadmap

### Phase 1 - Core Application Tracker

- Authentication
- Application CRUD
- Database
- Dashboard
- Application status
- Application source

### Phase 2 - Email Automation

- Gmail integration
- Application email detection
- Automatic application extraction
- Duplicate detection

### Phase 3 - Browser Extension

- Job information detection
- Application capture
- Job portal integration

### Phase 4 - Intelligence

- AI job/email parsing
- Automatic status updates
- Follow-up reminders
- Application analytics
